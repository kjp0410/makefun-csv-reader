A faster drop-in for csv-reader 1.0.0: a single-pass broken-CSV parser whose answers — columns, rows and errors — are identical to csv-reader's on every input, produced in less CPU time. `solve.js` exports `run({text, header})`; `main.ts` is the harness driver.

## Run it

```sh
node main.ts
```

`main.ts` reads the cases from `/input/cases.json` and writes the answers to `/output/answers.json`.
